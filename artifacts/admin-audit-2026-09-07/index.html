What is working

All 33 destinations are present. The first Module Configuration tab and editor, Holiday/Bank field inventories, Invoice Create and the inspected Help article are comparatively close. This is not a whole-module pass.

Highest-impact findings

P1 · Missing or wrong interactions

22b Template editor, 09b existing-contact picker, 27/27a Reallocation, 28/28a Deletion and 00a Directory do not reproduce their reference workflows. Restore the same visual entry points, forms and transitions using sample-only states.

P1 · Missing fields and states

06b/06d bucket/sub-status editors and 12b–12p nested Configuration screens omit controls, summaries, helpers or wizard paths. Match field inventory, labels, required markers, defaults, conditional visibility and disabled states before styling polish.

P1 · Premature enabled controls

07a Add Selected, 12f/26b Upload, 12l Sub Status and 24a OTP Update do not preserve reference prerequisites. Simulate prerequisites without enabling real server writes.

P1 · Readability and sample integrity

Dark text on purple panels affects several configuration, deletion, password and audit screens. Dashboard/notification sample states contradict their totals. Restore readable panel treatment, then validate actual contrast; make sample data internally consistent.

P1/P2 · Tables and composition

Customer bulk/contact/template tables change schemas; action columns disappear beyond horizontal scroll. Strategy Manager and Client Master differ substantially. Match column inventory/order, action placement, density and reference container structure.

P2 · Shared visual drift

Office Setup margins, header weights, modal widths/columns, button hierarchy, label casing, backdrop blur and pagination differ repeatedly. Standardize shared tokens/components, then re-capture each affected module at matched breakpoints.

Coverage limits, accessibility and evidence integrity
  • All 33 Admin navigation destinations were opened. The 103 paired states include landing pages, forms, selected tabs, dropdowns, wizards and safe error/empty states; they do not exhaust every conditional screen.
  • No Save, Upload, Delete, purge, credential sending, OTP/email sending, password update, ticket submission or feedback submission was executed. Unsaved selections were discarded. Backend functionality and persistence are outside this design-only audit.
  • User Setup step 2/edit/reset, bulk-user dialog, Limbo edit, customer edit/bulk dialog, alternate SMTP provider fields, deletion confirmation, uploaded-file results and every conditional Strategy path remain unverified.
  • The source had no tickets or sub-clients, so ticket conversations and linked sub-client detail could not be compared. One Template Edit record errored; a later record opened successfully and is included. Only one Help article body was compared, not the other 99.
  • Live and mock record contents/counts were not treated as visual failures. Internal contradictions (e.g. badge count versus empty panel, non-zero charts versus zero totals) were reported separately.
  • Matched pair viewports were 746×1120 or 1112×1120 CSS pixels, not a single desktop breakpoint. Screenshot-provider scaling and different scroll offsets are noted; this is not pixel-diff scoring. Mobile, 1440px+, 200% zoom, full keyboard/focus trapping, screen-reader behavior and measured WCAG contrast remain untested.
  • The requested one-line local tabs/headers are intentional and are not flagged simply for differing from reference wrapping. Reference clipping, awkward badges, green failure statuses, empty-state count anomalies and credential exposure should not be copied blindly.

URLs identify module landing routes, not guaranteed deep-state URLs. Per-capture DOM and original viewport records were not retained; encoded image dimensions and hashes are verified directly from saved files.

Accessibility risks: low-contrast headings, clipped dropdowns, icon-only/unnamed controls, weak disabled styling and missing dialog/expanded semantics. Targeted DOM observations supplement screenshots; keyboard and screen-reader testing and numerical contrast checks remain necessary.

Reference-side security concern: SMTP Edit exposes credential fields as plain text. Do not copy this behavior. Review masking and credential exposure with the security owner.

Business decisions before implementation
  • Should Strategy aging defaults (2 versus 19 selected) and Directory email-communication consent mirror the reference? These affect behavior and should not be silently chosen.
  • Should upload hints allow CSV, or only the reference XLSX/XLS formats? The audit flags the displayed contract, not backend file support.
  • Should the SMTP integration guide remain removed under the earlier remove-tutorials request? Its absence is a decision point, not an automatic defect.
Repair acceptance checklist
  1. Match workflow, field and table inventory before styling.
  2. Exercise populated, empty, selected, disabled, dropdown and modal sample states without persistence.
  3. Match labels, placeholders, spacing, type, buttons and icons.
  4. Re-capture at matched widths; add mobile, zoom and keyboard/focus tests.
  5. Close each issue against paired evidence and document intentional deviations.
